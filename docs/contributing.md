# Contributing to TaurusTLS

Thank you for taking the time to contribute! TaurusTLS is an open-source project, and contributions of all kinds are welcome and appreciated.

## Code and Issue Contributions

- **Report Bugs & Suggest Features:** Found an issue or have an idea? Open an issue on our [GitHub Issues](https://github.com/TaurusTLS-Developers/TaurusTLS/issues) page with steps to reproduce it.
- **Submit Pull Requests:** We welcome bug fixes, optimizations, and documentation updates. Feel free to open a [pull request](https://github.com/TaurusTLS-Developers/TaurusTLS/pulls).

## Community & Showcase

- **Showcase Your App:** If you built an application using TaurusTLS, share it in our [Show and Tell discussion forum](https://github.com/orgs/TaurusTLS-Developers/discussions/categories/show-and-tell) to be featured on our [Links Page](https://taurustls.org/links.xhtml).
- **Spread the Word:** Link back to the [TaurusTLS website](https://taurustls.org/) from your blog, portfolio, or documentation.
- **Star the Repo:** Star the [TaurusTLS repository](https://github.com/TaurusTLS-Developers/TaurusTLS) on GitHub to help more developers discover the project.

## Financial Support

- **Donate:** If you find TaurusTLS valuable, consider [making a donation](https://opencollective.com/TaurusTLS-Developers) on Open Collective to help support ongoing maintenance and project costs.
